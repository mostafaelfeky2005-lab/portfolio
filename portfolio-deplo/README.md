# موقع البورتفوليو الشخصي

موقع بورتفوليو احترافي وعصري (Dark / Blueprint theme) مبني بـ **HTML5 + Tailwind CSS + JavaScript**، وكل محتواه (النبذة، المهارات، المشاريع، روابط التواصل) يُقرأ من ملف واحد: **`data.json`**.

## بنية الملفات

```
portfolio-site/
├── index.html    ← هيكل الصفحة (لا تحتاج لتعديله عادةً)
├── app.js        ← يقرأ data.json ويبني كل الأقسام تلقائياً
├── data.json     ← كل المحتوى: اسمك، نبذتك، مهاراتك، مشاريعك، روابطك
└── README.md
```

## كيف تحدّث محتوى الموقع (بدون لمس الكود)

كل ما تحتاجه هو تعديل **`data.json`**:

- لإضافة مشروع جديد → أضف عنصر جديد داخل مصفوفة `"projects"` بنفس شكل العناصر الموجودة.
- لتحديث نبذتك أو مهاراتك أو بياناتك الشخصية → عدّل الحقول المقابلة في `"personal"` و `"about"` و `"skills"`.
- احفظ الملف وأعد تحميل الصفحة في المتصفح — الموقع سيعرض كل تعديل تلقائياً دون أي تدخل في `index.html` أو `app.js`.

مستقبلاً، ما عليك سوى أن تخبرني بالمشروع الجديد (العنوان، الوصف، الروابط، الوسوم) وسأحدّث لك `data.json` مباشرة.

## التشغيل محلياً (Localhost)

المتصفحات تمنع قراءة ملفات JSON بأمر `fetch` عند فتح `index.html` مباشرة (بروتوكول `file://`)، لذلك يجب تشغيل خادم محلي بسيط. اختر إحدى الطرق التالية من داخل مجلد `portfolio-site`:

**الطريقة 1 — عبر Python (غالباً مثبت مسبقاً):**
```bash
cd portfolio-site
python3 -m http.server 8000
```
ثم افتح المتصفح على: `http://localhost:8000`

**الطريقة 2 — عبر Node.js:**
```bash
cd portfolio-site
npx serve .
```

**الطريقة 3 — إضافة Live Server في VS Code:**
افتح المجلد في VS Code، ثبّت إضافة "Live Server"، ثم اضغط "Go Live" أسفل الشاشة.

## النشر (Deployment)

الموقع بالكامل ملفات ثابتة (Static)، لذلك يمكنك نشره مجاناً على أي من:

- **GitHub Pages**: ارفع المجلد إلى مستودع GitHub، ثم من إعدادات المستودع (Settings → Pages) فعّل النشر من الفرع الرئيسي.
- **Vercel** أو **Netlify**: اسحب المجلد مباشرة (Drag & Drop) على لوحة التحكم الخاصة بهما، أو اربط المستودع من GitHub — النشر يتم تلقائياً خلال ثوانٍ ويعطيك رابطاً مباشراً.

في الحالتين لا حاجة لأي إعداد بناء (Build) خاص لأن الموقع HTML/CSS/JS بحت.

## ملاحظات

- كل النصوص الحالية (الاسم، البريد، روابط GitHub/LinkedIn، أسماء المشاريع...) هي بيانات نموذجية (placeholder) — استبدلها ببياناتك الحقيقية في `data.json` قبل النشر.
- الخطوط مستوردة من Google Fonts وTailwind من CDN، لذا يحتاج المتصفح لاتصال إنترنت لعرض التصميم بأفضل شكل (يعمل محلياً وفي أي استضافة عادية).
- التصميم متجاوب بالكامل (Mobile / Tablet / Desktop) ويحترم إعداد "تقليل الحركة" في نظام التشغيل.
